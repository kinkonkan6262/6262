# 専用アイコン付きでお客様に渡す手順

## 結論

**可能です。** ただし、いま使っている `.lnk`（ショートカット）をそのまま渡しても、お客様のパソコンでは動きません。
代わりに、この `配布キット` の `ショートカット作成.bat` を一緒に渡します。

---

## なぜ .lnk をそのまま渡せないのか

お預かりした `Anna_AI支援記録Pro_v7.98.html - ショートカット.lnk` の中身を解析すると、次の情報が
**そのパソコン固有の絶対パス**で記録されています。

| 項目 | 記録されている値 |
|---|---|
| リンク先 | `C:\Users\kinkonkan\Desktop\Anna_AI支援記録Pro_v7.98.html` |
| アイコン | `%USERPROFILE%\Downloads\annafolder.ico` |
| 作成PC | `DESKTOP-H1NF0I5` |
| 開くアプリ | Microsoft Edge HTML Document |

お客様のパソコンには `kinkonkan` というユーザーも `annafolder.ico` も無いので、

- リンク先が見つからず起動できない
- アイコンが真っ白（既定のアイコン）になる

という状態になります。**アイコンの絵そのものは .lnk の中には入っていません**（場所を指しているだけ）。
なので `.lnk` を渡す方式ではなく、**お客様のパソコン上でショートカットを作り直す**方式にします。

---

## お客様に渡すもの（2ファイルだけ）

```
Anna_AI支援記録Pro_v7.98.zip
├─ Anna_AI支援記録Pro_v7.98.html      ← 本体（今まで通り）
├─ ショートカット作成.bat               ← アイコン入り（この配布キットのもの）
└─ お客様へ_はじめにお読みください.txt   ← 設置手順（この配布キットのもの）
```

`.ico` ファイルは **`.bat` の中に埋め込む**ので、別途渡す必要はありません。

> ### 【重要】ショートカット（.lnk）を渡してはいけません
>
> 自分のPCで出来たショートカットをコピーしてお客様に渡しても、**必ず失敗します**。
> ショートカットの中身は「道案内の紙」だけで、絵も本体も入っていないためです。
>
> ```
> 本体はここ     → C:\Users\kinkonkan\Desktop\Anna_AI支援記録Pro_v7.98.html
> アイコンはここ → C:\Users\kinkonkan\AppData\Local\Anna_AI\annafolder.ico
> ```
>
> お客様のPCに `kinkonkan` というユーザーは存在しないので、行き先も絵も見つからず、
> 白いアイコンで反応しない状態になります。
> **必ず `.bat` を渡して、お客様のPC側でショートカットを作ってもらってください。**

## お客様の操作（1回だけ）

1. ZIP を右クリック →「すべて展開」で、好きなフォルダに展開する
2. `ショートカット作成.bat` をダブルクリックする
3. デスクトップに専用アイコンの「Anna AI支援記録Pro」ができる

以降はそのアイコンをダブルクリックするだけで起動します。

> 「WindowsによってPCが保護されました」と出た場合は、
> 「詳細情報」→「実行」を押していただくようご案内してください
> （インターネット経由で受け取ったファイルに毎回出る標準の警告です）。

## 販売元での準備（バージョンアップのたびに行う作業）

### 1. アイコンを .bat に埋め込む → **完了済み**

`ショートカット作成.bat` には `annafolder.ico`（16/32/48/64/128/256 px の6サイズ入り、37,173バイト）
を**埋め込み済み**です。そのままお客様に渡せます。

アイコンの絵柄を変更したときだけ、次のコマンドで入れ替えてください。

```bash
python3 icon_tool.py embed-bat annafolder.ico ショートカット作成.bat
```

バージョンアップのたびに `.bat` を作り直す必要はありません。**同じ `.bat` を毎回使い回せます**
（本体HTMLのファイル名は自動で検出するため、v7.98 → v7.99 になっても差し替え不要です）。

### 2. HTML 本体にもアイコンを埋め込む（推奨）

```bash
python3 icon_tool.py embed-html annafolder.ico Anna_AI支援記録Pro_v7.98.html
```

`<head>` に画像を直接埋め込むので、**HTML 1ファイルのまま**で次が効きます。

| 使い方 | アイコンの出方 |
|---|---|
| ブラウザのタブ | 専用アイコンが表示される |
| お気に入り／ブックマーク | 専用アイコンが表示される |
| スマホ「ホーム画面に追加」 | アプリのように専用アイコンで並ぶ |

（元ファイルは `.html.bak` として自動でバックアップされます）

### 3. ZIP にまとめて配布

`Anna_AI支援記録Pro_vX.XX.html` と `ショートカット作成.bat` の 2 つを ZIP にして渡します。

## 仕組み（ショートカット作成.bat が行うこと）

1. **ZIPの中から直接実行されていないか確認する**
   （展開せずに実行すると一時フォルダに展開されるため、そこにショートカットを作ると
   あとで一時フォルダごと消えて動かなくなる。検出したら手順を案内して中止する）
2. 同じフォルダにある `Anna_AI*.html` を自動で探す（複数あれば更新日時が最新のもの）
3. 対象ファイル名を画面に表示し、キー入力を待つ（間違ったファイルなら閉じてもらう）
4. 末尾に埋め込まれたアイコンを `%LOCALAPPDATA%\Anna_AI\annafolder.ico` に書き出す
   （安定した場所に置くので、後でフォルダを移動してもアイコンは消えません）
5. デスクトップに `Anna AI支援記録Pro.lnk` を作り、リンク先とアイコンを**そのパソコンの実際のパス**で設定する
6. 全工程を `Anna_診断ログ.txt` に記録する（トラブル時はこれを送ってもらう）

管理者権限は不要です。レジストリも変更しません。
デスクトップの場所は Windows の API から取得するので、OneDrive で
デスクトップが同期されているパソコンでも正しい場所に作られます。

## 注意点

- **本体HTMLを別フォルダへ移動したときは、移動先で `.bat` をもう一度実行**してください
  （ショートカットのリンク先が変わるため）
- 入力済みのデータはブラウザ内（localStorage）に保存されるため、HTMLファイルを移動しても消えません。
  ただし**別のブラウザで開くとデータは引き継がれません**（例：Edge で使っていた方が Chrome で開く）。
  ショートカットは既定のブラウザで開くので、お客様が普段お使いのブラウザから変えないようご案内してください。
- `annafolder.ico` は 16／32／48／256 ピクセルを含むマルチサイズのアイコンにしておくと、
  デスクトップでも一覧表示でもきれいに表示されます。
